Command your dracula

Discover the list of commands available for interacting with the bot and configuring your space.

Commande 01

The first command?

/setup

This is the text that appears on Discord when you type the command /setup.

Account creation

This is the interface that appears when you click "Create an account." Simply enter your email address to receive a unique verification code.

Commande 02

The second command?

/help

By executing the command/help, you instantly display the complete list of all commands available for use by the bot on the server.

Commande 03

The third command?

/admin-panel

Order fulfillment /admin-panel opens access to the administration panel, allowing you to list and track all users who have an active account on the server.

Commande 04

The fourth command?

/ping

La commande /pingallows you to instantly test the latency and status of the real-time communication between the bot and Discord's servers.

Fichier de Configuration .env
DISCORD_TOKEN="YOUR_DISCORD_BOT_TOKEN"
RESEND="re_YOUR_API_KEY"
MAIL_PWD="YOUR_SMTP_PASSWORD"
MAIL_FORM='mymail@example.com'
SMTP_SERVER='://example.com'
MAIL_USERNAME='mymail@example.com'
MAIL_PORT=587
Variable Purpose
DISCORD_TOKENYour Discord bot token.
RESENDYour Resend API key, if your code uses this service.
MAIL_PWDYour SMTP password or provider-specific SMTP secret.
MAIL_FORMThe sender email address expected by your code. Check the exact variable name in your code.
SMTP_SERVERThe address of your SMTP server.
MAIL_USERNAMEThe username used for SMTP authentication, often an email address.
MAIL_PORTThe SMTP port. 587 is commonly used with STARTTLS.
