bot-discord

Get your Discord bot

Follow this guide to add the bot to your Discord server, authorize it and get started.

Step 01

Discord account

You need a Discord account and a server where you have permission to add bots.

Already have an account?

Log in to your existing Discord account.

Login with Discord ↗

New to Discord?

Create an account before continuing.

Create an account ↗

Step 02

Get the bot

To add the bot to your server, you need its official invitation link. Ask the bot's creator or check the project's official page to find it.

Official bot invitation

Use the invitation link provided by the developer.

ⓘ The bot's invitation link has not been provided yet. Do not use a random link from an unknown source.

Step 03

Choose your server

Open the official invitation link. Discord will ask you which server you want to add the bot to.

Before continuing

  • Select the correct server from the list.
  • Make sure you have permission to manage that server.
  • If the server is missing, check your server permissions.

Step 04

Authorize the bot

Review the permissions requested by the bot before confirming the authorization.

Check the permissions

  • Read the permissions requested by the bot.
  • Make sure the requested access is appropriate.
  • Click Authorize to complete the process.
! Only authorize bots from a source you trust. Never share your Discord password or token.

Step 05

Check the installation

Once authorized, return to your Discord server and check that the bot has joined successfully.

Bot is visible

Look for the bot in the server member list. Its online status may depend on whether it is running.

Bot is not responding

Check its permissions and make sure the developer has the bot running.

Step 06

Configure your bot

Your bot may provide tools for server management and questionnaires. Available features depend on the actual bot implementation.

Ready to get started?

Check the bot's available commands, help messages or documentation to learn how to use its features.
