Contributing to the bot

Contributions help improve the Discord bot, its documentation and the experience of its users.

Why contribute?

You can help by reporting bugs, improving instructions, suggesting useful features or contributing code. If you are new to the project, start by describing the problem or idea clearly.

Ways to contribute

ContributionWhat to doDifficulty
Report a bugExplain what happened and how to reproduce it.Easy
Improve documentationCorrect errors or clarify installation and configuration steps.Easy
Suggest a featureDescribe the feature and the problem it would solve.Easy
Contribute codeImplement a fix or feature after discussing it with the maintainers.Intermediate

How to contribute

  1. Check existing issues. Look for a similar report or proposal before opening a new one.
  2. Explain your change. Describe the issue, expected behaviour and proposed solution.
  3. Work on a separate branch. Keep your changes focused so they are easier to review.
  4. Test your changes. Check that the bot or documentation still works as expected.
  5. Submit your contribution. Open a pull request and explain what you changed.
Open the GitHub profile ↗
ⓘ Be respectful, protect private information and never include Discord bot tokens, passwords or other secrets in issues or commits.

Before submitting

  • Keep changes consistent with the existing project.
  • Write clear descriptions and commit messages.
  • Do not commit tokens, credentials or private server information.
  • Document any new commands or configuration options.
